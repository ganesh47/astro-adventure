# Security

Do not post signing certificates, provisioning profiles, App Store Connect credentials, API private keys, authentication tokens, personal player data, TestFlight exports, or signed distribution artifacts in public issues, pull requests, discussions, commits, or wiki pages.

If you find sensitive material or a vulnerability in the public repository, use GitHub's [private vulnerability reporting](https://github.com/ganesh47/astro-adventure/security/advisories/new). Avoid opening a public issue or quoting the secret in public.

Security reports should include the affected version, impact, reproduction conditions, and a safe contact method. Reports about child privacy or unintended data collection are treated as high priority.

Supported security fixes target the latest commit on `main`. Alpha tags are provided for evaluation and do not receive independent long-term security maintenance.
